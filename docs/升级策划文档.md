# 《萌宠大冒险》升级策划文档

**文档版本**: v1.0  
**制定日期**: 2026年5月9日  
**文档状态**: 初稿  
**目标**: 基于竞品分析，制定详细的升级方案

---

## 一、核心玩法创新点

### 1.1 创新理念: "治愈系Roguelike"

**核心差异**: 区别于市场上硬核Roguelike（如吸血鬼幸存者）和传统萌宠收集游戏，打造"零压力、高反馈、强收集"的治愈系体验。

### 1.2 具体创新设计

#### 创新1: "心情系统" - 情感化养成

**设计目标**: 让萌宠不只是战斗工具，而是有情感连接的伙伴

**系统规则**:
```
【心情值机制】
- 每只萌宠有独立心情值 (0-100)
- 战斗胜利 +5心情，失败 -10心情
- 长时间不上阵 -1心情/天
- 喂食/互动 +10心情

【心情效果】
- 心情80-100: 战斗属性+10%，掉落率+20%
- 心情50-79: 正常状态
- 心情20-49: 战斗属性-10%
- 心情0-19: 拒绝出战，需要安抚

【互动玩法】
- 抚摸: 点击萌宠播放互动动画
- 喂食: 消耗食物道具提升心情
- 玩耍: 小游戏互动，大幅提升心情
```

**预期效果**:
- 提升用户情感连接和留存
- 增加一个养成维度，延长游戏生命周期
- 创造新的付费点（食物道具）

---

#### 创新2: "羁绊连携" - 策略深度提升

**设计目标**: 让阵容搭配更有策略性，鼓励收集更多萌宠

**系统规则**:
```
【羁绊类型】
1. 属性羁绊: 同属性萌宠上阵触发
   - 2只火系: 火伤+15%
   - 3只火系: 火伤+30%，附加燃烧效果

2. 种族羁绊: 特定种族组合触发
   - 猫科组合: 攻速+20%
   - 龙族组合: 全属性+10%
   - 神兽组合: 开场满能量

3. 故事羁绊: 有背景关联的萌宠组合
   - 光暗双子: 光暗同时上阵，互相强化
   - 元素守护者: 火水草同时上阵，触发元素风暴

【连携技能】
- 特定组合在战斗中可触发连携技
- 例如: 火焰喵+雷霆熊 = "雷火交加"（范围伤害）
```

**UI展示**:
- 阵容编辑界面显示羁绊激活状态
- 战斗内触发连携时播放特殊动画
- 图鉴中显示萌宠的羁绊关系网

---

#### 创新3: "梦境冒险" - 离线收益创新

**设计目标**: 解决放置类游戏"上线收菜"的枯燥感，增加惊喜元素

**系统规则**:
```
【梦境机制】
- 下线后萌宠会进入"梦境冒险"
- 根据上阵萌宠和时长，自动进行虚拟战斗
- 再次上线时收获梦境奖励

【梦境类型】
- 普通梦境: 基础资源收益
- 噩梦: 有战斗失败风险，但收益更高
- 美梦: 必定获得稀有道具

【互动元素】
- 可以"托梦"给好友的萌宠（社交互动）
- 梦境中可能遇到"神秘商人"（限时购买）
- 连续登录触发"连环梦境"（收益递增）
```

**差异化价值**:
- 区别于传统"挂机收益"，增加随机性和故事感
- "梦境"概念与"萌宠"主题契合
- 创造社交互动新场景

---

#### 创新4: "季节限定" - 限时收集驱动

**设计目标**: 创造稀缺性和紧迫感，驱动短期留存和付费

**系统规则**:
```
【季节系统】
- 现实世界季节与游戏同步
- 每个季节推出3-5只限定萌宠
- 限定萌宠只能通过季节活动获得

【季节活动】
- 春季: "花开时节" - 花系萌宠up
- 夏季: "海滩派对" - 水系萌宠up
- 秋季: "丰收祭" - 草系萌宠up
- 冬季: "冰雪节" - 冰系萌宠up

【复刻机制】
- 限定萌宠一年后可能复刻
- 不复刻的萌宠会进入"绝版"状态，增加收藏价值
```

## 二、新增系统功能

### 2.1 装备系统（符文之语）

**系统定位**: 提供Build深度，增加数值成长维度

**设计详情**:
```
【装备类型】
- 武器: 提升攻击力
- 护甲: 提升生命值
- 饰品: 特殊效果（暴击/吸血等）
- 符文: 镶嵌在装备上，提供额外属性

【装备品质】
- 普通(白) → 魔法(蓝) → 稀有(紫) → 传说(橙)
- 品质越高，属性越好，可镶嵌符文槽越多

【符文系统】
- 符文有类型和等级
- 特定符文组合触发"符文之语"（强力特效）
- 例如: 火符文+攻击符文 = "烈焰之力"（火伤+30%）

【获取途径】
- 关卡掉落
- 合成系统（3合1升品质）
- 商店购买
- 活动奖励
```

**与现有系统融合**:
- 装备可在Roguelike战斗中获得（作为技能选择的一种）
- 装备强化消耗金币和材料（材料来自关卡）
- 高稀有度装备可分解为符文

---

### 2.2 家园系统（萌宠公寓）

**系统定位**: 提供治愈系核心体验，增加用户粘性

**设计详情**:
```
【家园基础】
- 玩家拥有一个可自定义的"萌宠公寓"
- 公寓有多个房间，每个房间可放置萌宠

【家具装饰】
- 家具分为: 功能型（增加收益）和装饰型（纯美观）
- 家具可通过游戏内货币或付费获得
- 特定家具组合触发"套装效果"

【萌宠互动】
- 萌宠在家园中自由活动
- 萌宠之间会触发随机互动事件
- 玩家可点击萌宠进行互动（抚摸、喂食、玩耍）

【访客系统】
- 好友可以访问你的家园
- 访客可以"点赞"获得奖励
- 家园热度排行榜

【收益机制】
- 家园每小时产生少量金币
- 家具可提升收益效率
- 萌宠心情影响收益
```

**美术需求**:
- 房间背景（5-10种风格）
- 家具素材（30-50件）
- 萌宠Q版形象（用于家园展示）
- 互动动画

---

### 2.3 师徒系统（社交裂变）

**系统定位**: 驱动病毒传播，帮助新手成长

**设计详情**:
```
【师徒关系】
- 等级>30的玩家可收徒
- 等级<15的玩家可拜师
- 每位师父最多同时有3位徒弟

【徒弟福利】
- 师父助战: 可借用师父的一只萌宠
- 经验加成: 与师父组队战斗经验+20%
- 出师奖励: 达到30级获得丰厚奖励

【师父福利】
- 徒弟成长奖励: 徒弟升级师父获得奖励
- 出师大奖: 徒弟出师师父获得稀有道具
- 名师称号: 出师徒弟数量达到一定程度获得称号

【师徒任务】
- 每日师徒专属任务
- 完成任务双方都有奖励
- 促进师徒互动
```

**传播设计**:
- 拜师需要分享邀请码/链接
- 出师后可选择"成为师父"继续传播
- 名师排行榜激励竞争

---

### 2.4 公会系统（萌宠联盟）

**系统定位**: 提供社交归属感和团队协作玩法

**设计详情**:
```
【公会基础】
- 玩家可创建或加入公会
- 公会等级影响人数上限和福利
- 公会成员可互相赠送体力

【公会活动】
1. 公会战: 与其他公会竞争排名
2. 公会BOSS: 全公会合力挑战
3. 公会任务: 集体完成获得奖励
4. 公会商店: 用贡献度兑换稀有道具

【公会科技】
- 公会可研发"科技"提升全体成员属性
- 科技需要成员贡献资源升级
- 科技类型: 攻击/生命/金币收益/经验收益

【公会福利】
- 每日签到奖励
- 公会等级奖励
- 公会战排名奖励
```

---

### 2.5 成就与收藏系统升级

**现有基础**: 已有25个基础成就

**升级方案**:
```
【成就扩展】
- 成就数量扩展至100+
- 成就分类: 战斗/收集/养成/社交/探索
- 成就等级: 铜/银/金/钻石

【收藏系统】
- 萌宠图鉴: 收集进度展示
- 皮肤收藏: 展示拥有的皮肤
- 纪念册: 记录游戏里程碑

【展示系统】
- 个人主页可展示成就和收藏
- 称号系统: 完成特定成就获得称号
- 头像框: 达成条件获得特殊头像框
```

## 三、美术风格定位

### 3.1 整体风格: "治愈系水彩童话风"

**风格定义**:
- **治愈**: 温暖、柔和、无攻击性的视觉感受
- **水彩**: 类似手绘水彩画的质感，边缘柔和
- **童话**: 梦幻、可爱、富有想象力的世界观

### 3.3 萌宠设计规范

**设计原则**:
1. **可爱优先**: 大眼睛、圆身体、短四肢
2. **识别度高**: 每只萌宠有独特特征
3. **情感表达**: 能传达不同情绪（开心、生气、困倦等）
4. **动画友好**: 适合制作待机动画和互动动画

**萌宠分类设计**:
```
【N级萌宠 - 基础可爱】
- 设计: 简单几何形状+动物特征
- 示例: 圆形身体+猫耳+大眼睛
- 数量: 20只

【R级萌宠 - 个性鲜明】
- 设计: 加入职业/元素特征
- 示例: 火焰喵（猫+火焰元素）
- 数量: 15只

【SR级萌宠 - 华丽精致】
- 设计: 复杂装饰+特效元素
- 示例: 凤凰（羽毛细节+火焰特效）
- 数量: 10只

【SSR级萌宠 - 震撼视觉】
- 设计: 全屏特效+独特造型
- 示例: 创世神（神圣光环+星辰特效）
- 数量: 5只
```

### 3.4 UI设计规范

**界面风格**:
- 圆角设计: 所有按钮和面板使用大圆角（16-24px）
- 柔和阴影: 轻微投影增加层次感
- 渐变背景: 使用柔和渐变替代纯色
- 手绘元素: 边框、装饰使用手绘风格

**字体规范**:
- 标题: 圆润可爱字体（如站酷快乐体）
- 正文: 清晰易读字体（如思源黑体）
- 数字: 等宽字体，重要数字使用特效

**动效规范**:
- 缓动函数: 使用ease-out，避免生硬感
- 时长: 200-400ms，快速响应
- 反馈: 所有点击都有视觉反馈
- 特效: 抽卡、升级等重要时刻使用粒子特效

### 3.5 AI美术生产流程

**工具选择**:
- **Midjourney**: 生成萌宠原画概念图
- **Stable Diffusion**: 精修和风格统一
- **Upscayl**: 图片放大
- **Photoshop**: 后期调整和切图

**生产流程**:
```
1. 概念设计 (人工)
   ↓ 输出: 文字描述+参考图
2. AI生成 (Midjourney)
   ↓ 输出: 4-8张概念图
3. 筛选精修 (人工+SD)
   ↓ 输出: 选定图片精修
4. 风格统一 (SD)
   ↓ 输出: 统一风格的成品
5. 后期处理 (PS)
   ↓ 输出: 切图+导出
6. 导入引擎 (Cocos)
```

## 四、社交/竞技元素

### 4.1 病毒传播机制

#### 机制1: "分享复活"

**规则**:
- 战斗失败后，可选择分享复活
- 每日前3次分享复活免费
- 后续分享复活需要看激励视频

**分享文案**:
```
"我的小火苗在第15波倒下了，快来帮我复活继续冒险吧！"
"就差一点点！帮我复活，一起冲击更高波数！"
```

---

#### 机制2: "好友助力抽卡"

**规则**:
- 每日可进行1次"助力抽卡"
- 需要3位好友点击助力链接
- 助力完成后获得免费抽卡1次

**传播设计**:
- 助力者也能获得小额奖励（钻石*10）
- 新用户首次助力额外奖励
- 显示"已有XX位好友助力"进度

---

#### 机制3: "拼团抽卡"

**规则**:
- 发起10连抽拼团，邀请好友参与
- 5人成团，每人只需支付半价（450钻石）
- 团长额外获得1次单抽机会

**传播设计**:
- 拼团链接24小时有效
- 拼团失败全额退款
- 显示拼团进度和剩余时间

---

### 4.2 竞技系统

#### 竞技场（异步PVP）

**规则**:
- 玩家设置防守阵容
- 挑战其他玩家的防守阵容（AI控制）
- 根据胜负获得/失去积分
- 赛季制，每月重置

**奖励**:
- 每日排名奖励
- 赛季结算奖励（限定皮肤/头像框）
- 积分商店兑换稀有道具

**防挫败设计**:
- 挑战失败不扣分（只加少量分）
- 显示"可战胜"标签帮助选择对手
- 提供"复仇"功能

---

#### 排行榜系统升级

**现有**: 简单的波数排行榜

**升级方案**:
```
【多维度排行榜】
1. 无尽模式榜: 最高波数
2. 战力榜: 总战力排名
3. 收集榜: 萌宠收集数量
4. 成就榜: 成就点数
5. 公会榜: 公会综合实力

【排行榜细分】
- 好友榜: 与好友比较
- 全区榜: 服务器排名
- 全国榜: 全服排名

【排行榜奖励】
- 周榜结算: 前100名获得奖励
- 月榜结算: 前10名获得限定称号
- 榜一专属: 全服公告+专属头像框
```

---

#### 限时挑战赛

**设计**:
- 每周一个主题挑战（如: 只用N级萌宠挑战）
- 所有玩家在相同条件下竞争
- 根据排名获得奖励

**主题示例**:
- "火之试炼": 只能用火系萌宠
- "极限生存": 敌人攻击力翻倍
- "速通挑战": 最快通关时间

---

### 4.3 社交互动

#### 好友系统升级

**现有功能**: 添加好友、赠送体力

**新增功能**:
```
【助战系统】
- 可借用好友的萌宠助战（每日限3次）
- 助战萌宠战力根据好友实际战力
- 好友获得助战奖励（少量钻石）

【萌宠交换】
- 好友间可交换萌宠碎片
- 每日交换上限10片
- 交换比例1:1

【私聊系统】
- 基础文字聊天
- 快捷短语（表情包）
- 分享战斗录像
```

## 五、商业化设计

### 5.1 付费点设计

#### 现有付费点分析

| 付费点 | 类型 | 定价 | 评估 |
|:---|:---|:---:|:---|
| 单抽 | 消耗 | 100钻石 | ✅ 合理 |

#### 新增付费点

**1. 战令系统（Battle Pass）**

```
【定价】
- 普通版: 免费
- 进阶版: 68元
- 精英版: 128元（含限定SSR）

```

- 金币: 游戏内获得，用于基础养成
- 体力: 时间恢复，限制游戏进度
- 友情点: 好友互动获得，兑换特定物品

【代币】
- 抽卡券: 相当于钻石，专用于抽卡
- 竞技场币: 竞技场获得
- 公会贡献: 公会活动获得
