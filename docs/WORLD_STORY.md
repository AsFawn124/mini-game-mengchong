## 世界观：星灵纪元

### 创世神话

在远古时代，世界由**五大元素之灵**共同守护：

> 🔥 **炎之主·祝融** — 执掌毁灭与新生之火
> 💧 **海之主·共工** — 执掌生命与净化之水  
> 🌿 **森之主·句芒** — 执掌生长与复苏之木
> ✨ **光之主·曦和** — 执掌秩序与希望之光
> 🌑 **暗之主·烛龙** — 执掌轮回与守护之暗

五大灵主共同创造了最初的**108只始祖萌宠**，每只都承载着一份世界法则的碎片。它们被分散在世界各地，等待着有缘人的召唤。

千年前，一场被称为**「裂界之灾」**的浩劫撕裂了大陆。封印的混沌之力泄漏，将部分萌宠变成**「堕化体」**。五位灵主耗尽力量将混沌重新封印，但自身也陷入沉睡。

自那以后，能召唤并训练萌宠的人类被称为**「契约师」**。

## 剧情章节

### 序章：新手契约师

玩家在萌宠花园醒来，被导师**艾琳**救起。她发现玩家体内有罕见的「全元素亲和力」——这意味着你能契约所有元素萌宠。

- **引导关卡1**：选择初始萌宠（火/水/草三选一）
- **引导关卡2**：学习战斗基础
- **引导关卡3**：学习抽卡和进化
- **引导关卡4**：击败花园中的堕化萌宠
- **Boss战**：翠玉龙（被混沌侵蚀的花园守护者）

### 第一章：烈焰试炼 🔥

**剧情**：烈焰火山最近异常活跃，火山口的封印正在松动。艾琳推测火山深处的炎之主祝融可能正在苏醒。

| 关卡 | 名称 | 剧情 | 新萌宠 |
|:---:|------|------|------|
| 1-1 | 火山山脚 | 遭遇野生火系萌宠袭击 | 火苗鼠(R) |
| 1-2 | 熔岩洞穴 | 发现古代火系契约师的遗迹 | 熔岩龟(SR) |
| 1-3 | 炎之试炼 | 接受炎之主残魂的考验 | 火凤雏(SSR) |
| 1-4 | 封印之地 | 解开封印，遭遇堕化守卫 | - |
| 1-5 | **Boss: 焰龙王** | 击败被混沌侵蚀的炎龙 | 👑焰龙王(SSR) |

**关键抉择**：击败焰龙王后，可以选择「净化」或「契约」它。
- 净化：获得炎之主祝福（火系萌宠全属性+10%）
- 契约：焰龙王成为可召唤萌宠

### 第二章：深海迷踪 💧

**剧情**：火山平息后，沿海城镇开始出现反常潮汐。深海遗迹的方向传来求救信号——这是水族萌宠的悲鸣。

| 关卡 | 名称 | 剧情 |
|:---:|------|------|
| 2-1 | 潮汐海岸 | 退潮时进入遗迹入口 |
| 2-2 | 珊瑚迷宫 | 穿越会变化的珊瑚通道 |
| 2-3 | 沉船坟场 | 在海底沉船中寻找钥匙 |
| 2-4 | 冰晶宫殿 | 发现被冰冻的古代契约师 |
| 2-5 | **Boss: 沧澜鲸** | 深海巨兽的愤怒 |

### 第三章：密林阴影 🌿

**剧情**：翡翠密林的古树开始枯萎。调查发现，一个自称「混沌教会」的组织正在抽取森林的生命力。

| 关卡 | 名称 | 剧情 |
|:---:|------|------|
| 3-1 | 林中小径 | 救助受伤的草系萌宠 |
| 3-2 | 精灵之泉 | 泉水中毒，找到污染源 |
| 3-3 | 混沌教会前哨 | 首次遭遇混沌教会成员 |
| 3-4 | 世界之树 | 古树的内心世界 |
| 3-5 | **Boss: 远古树人** | 被控制的森林守护者 |

**剧情转折**：混沌教会的首领现身——他竟然是艾琳失散多年的哥哥**阿尔文**。阿尔文认为只有释放混沌之力，才能超越元素之灵的"枷锁"，让人类获得真正的自由。

### 第四章：光暗交织 ✨🌑

**剧情**：同时探索星空神殿和暗影深渊，揭示混沌教会的真正目的——他们想同时解开光暗两处的封印，让混沌彻底降临。

**双线叙事**：
- 光之线：星空神殿 → 获得光之试炼 → 对阵混沌教会光系部队
- 暗之线：暗影深渊 → 了解暗之主的历史 → 发现混沌的真相

| 关卡 | 名称 | 特殊机制 |
|:---:|------|------|
| 4-1 | 云中阶梯 | 需要飞行萌宠才能进入 |
| 4-3 | 深渊裂隙 | 需要暗系萌宠引路 |
| 4-5 | **双Boss战** | 光暗同时作战，需要分开队伍 |

**剧情转折**：真相揭露——混沌不是敌人。五大灵主当初封印的不是邪恶，而是世界的「第六元素」——**混沌**。混沌是创造与毁灭的本源，封印混沌导致了世界法则的逐渐崩坏。混沌教会的错误在于想要「释放」而非「调和」。

### 终章：调和之路 🌈

**剧情**：说服阿尔文停止释放混沌，转而寻找「调和」第六元素的方法。

| 关卡 | 名称 | 剧情 |
|:---:|------|------|
| 5-1 | 五灵试炼 | 分别通过五元素试炼 |
| 5-2 | 记忆回廊 | 进入灵主们的记忆 |
| 5-3 | 混沌之心 | 深入混沌核心 |
| 5-4 | 调和仪式 | 保护仪式不受干扰 |
| 5-5 | **最终Boss: 混沌化身** | 调和前的最后考验 |

**结局**：第六元素被成功调和，世界法则恢复完整。五大灵主从沉睡中苏醒，108只始祖萌宠全部重现世间。阿尔文继承混沌之力成为**第六契约师**——混沌契约师。

## 新玩法系统

### 1. 契约师成长系统

| 等级 | 解锁 |
|:---:|------|
| 1-10 | 基础战斗、抽卡、进化 |
| 10 | 世界地图探索 |
| 15 | PvP竞技场 |
| 20 | 公会系统 |
| 25 | 繁衍融合 |
| 30 | 第六元素觉醒（混沌系萌宠） |
| 40 | 第二契约槽（同时召唤2只萌宠） |
| 50 | 元素共鸣（队伍全同元素触发隐藏效果） |

### 2. 剧情分支系统

在关键节点做出选择，影响：
- 可获得的萌宠（净化/契约）
- NPC关系（与阿尔文是敌是友）
- 结局走向（完美结局/普通结局/隐藏结局）
- **多周目继承**：二周目可选择不同路线

### 3. 萌宠羁绊系统

培养时间和使用频率影响萌宠的**羁绊值**：
- Lv1：属性+5%
- Lv2：解锁专属技能动画
- Lv3：解锁隐藏技能
- Lv4：解锁专属剧情（每只UR/SSR独立小故事）
- Lv5：羁绊形态（外观变化 + 属性+20%）

### 4. 遗迹探索玩法

每张地图有**隐藏遗迹**，需要特定条件触发：
- 收集特定萌宠才能进入
- 遗迹中有古代契约师留下的试炼
- 通关获得**传说级道具/限定萌宠**
- 全服首通会全服广播

### 5. 赛季故事

每个赛季围绕一个主题展开支线故事：
- S1：圣光凤凰的试炼（光系赛季）
- S2：深海宝藏（水系赛季）
- S3：混沌侵袭（暗系赛季）
- S4：百宠祭典（全系狂欢·周年庆）

## 剧情写作指南

### 基调
温暖治愈为主，深度剧情为辅。日常剧情轻松可爱，主线剧情有足够的深度。

### 叙事手法
1. **立绘对话**：主要剧情用2D立绘+对话框（类似Galgame）
2. **萌宠日记**：每只SR+萌宠都有短篇背景故事
3. **场景插画**：关键剧情节点配插画
4. **语音点缀**：核心剧情句配音（如Boss战前宣言）
5. **环境叙事**：场景中的细节讲述隐藏故事

### 情感曲线
```
第一章：好奇 → 激动 → 决心
第二章：温暖 → 悲伤 → 坚定
第三章：信任 → 背叛 → 困惑
第四章：迷茫 → 领悟 → 觉醒
终章：  决心 → 牺牲 → 和解 → 希望
```
