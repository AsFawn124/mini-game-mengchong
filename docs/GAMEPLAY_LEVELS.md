## 战斗系统深化

### 1. 元素连携系统

当队伍中萌宠的元素形成特定组合时，触发**元素连携效果**：

| 组合 | 名称 | 效果 |
|------|------|------|
| 🔥+💧+🌿 | 三元调和 | 全队伤害+15%，受伤害-15% |
| 🔥+🔥+🔥 | 烈焰风暴 | 火系伤害+40%，每回合灼烧敌人 |
| 💧+💧+💧 | 深海领域 | 每回合回复10%HP |
| 🌿+🌿+🌿 | 生命之树 | 复活被击败的萌宠1次 |
| ✨+✨ | 圣光庇护 | 免疫一次致命伤害 |
| 🌑+🌑 | 暗影低语 | 暴击率+30% |
| ✨+🌑 | 光暗交融 | 无视属性克制，对所有属性+20%伤害 |
| 🔥💧🌿✨🌑 | 五行归一 | **全属性+30%**，每回合随机触发元素效果 |

### 2. 萌宠阵型系统

```
前排(1位) ─── 承受伤害优先，适合高防/高HP萌宠
中排(2位) ─── 平衡位置，适合综合型萌宠
后排(2位) ─── 被攻击概率低，适合高攻/治疗萌宠

阵型加成：
一字阵:    攻+10% 防-5%  速+0%   (均衡)
三角阵:    攻-10% 防+15% 速-5%   (防御)
飞翼阵:    攻+15% 防-10% 速+10%  (速攻)
圆阵:      攻+0%  防+5%  速+0%   (回复+20%)
```

### 3. 装备系统

每个萌宠可装备3件：

| 部位 | 槽位1 | 槽位2 | 槽位3 |
|:---:|:---:|:---:|:---:|
| 🔧 | 武器(攻) | 饰品(速) | 防具(防) |
| 稀有度 | 白/绿/蓝/紫/金/红 | 同左 | 同左 |
| 套装 | 2件套+5%属性 | 3件套触发额外技能 | - |

**套装例子**：
- 🐉 龙族套装(3件)：龙系技能伤害+30%
- 🌸 樱花套装(3件)：每回合回复最大HP的5%
- ⚡ 雷霆套装(3件)：速度+20%，先手攻击+50%伤害
- 🛡️ 铁壁套装(3件)：受到伤害-25%，无法被暴击

## 关卡类型设计

### 类型1：常规关卡（70%）
标准3v3或5v5回合对战，击败所有敌人通关。

### 类型2：Boss关卡（15%）
1v1大型Boss战，Boss拥有多个阶段和特殊机制。

### 类型3：生存关卡（10%）
连续多波敌人，每波后回复少量HP。存活N波通关。

### 类型4：限时关卡（3%）
在规定回合数内击败敌人，超时失败。

### 类型5：解谜关卡（2%）
需要特定元素/稀有度/萌宠组合才能通关。

  1. 龙息 (单体150%伤害) - 每3回合

首通奖励: 👑焰龙王(SSR) + 500金币 + 100钻石
重复奖励: 焰龙鳞片(兑换材料)x5 + 100金币

## 萌宠养成深度

### 进化系统

```
N → R → SR → SSR → UR (传说进化)

进化条件:
- N→R: Lv10 + 进化石x1 + 100金币
- R→SR: Lv20 + 进化石x5 + 属性之石x1 + 500金币
- SR→SSR: Lv30 + 进化石x20 + 属性之石x5 + 2000金币 + 完成专属试炼
- SSR→UR: Lv50 + 传说进化石x1 + 全属性之石x3 + 10000金币 + 羁绊Lv5
```

### 技能学习系统

每只萌宠有4个技能槽：

| 槽位 | 解锁等级 | 类型 |
|:---:|:---:|------|
| 1 | 初始 | 基础攻击 |
| 2 | Lv5 | 主动技能(可选学) |
| 3 | Lv15 | 主动技能(可选学) |
| 4 | Lv30 | 终极技能(种族专属) |

技能可通过**技能书**学习和替换，稀有技能书可从：
- 遗迹探索掉落
- PvP排名奖励
- 活动兑换
- 公会商店

### 星阶突破

消耗同稀有度的**萌宠碎片**提升星阶(1-7星)：

| 星阶 | 碎片需求 | 属性提升 |
|:---:|:---:|:---:|
| 1→2 | 10 | +10% |
| 2→3 | 20 | +10% |
| 3→4 | 50 | +15% |
| 4→5 | 100 | +15% |
| 5→6 | 200 | +20% |
| 6→7 | 500 | +30% (解锁觉醒外观) |
