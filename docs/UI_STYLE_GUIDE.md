## 4. 阴影规范

### 4.1 阴影层级

| 层级 | 阴影值 | 用途 |
|:---:|:---:|:---|
| 一级阴影 | `0 2px 8px rgba(0,0,0,0.08)` | 卡片默认状态 |
| 二级阴影 | `0 4px 16px rgba(0,0,0,0.12)` | 按钮悬停、卡片悬停 |
| 三级阴影 | `0 8px 24px rgba(0,0,0,0.16)` | 弹窗、浮层 |
| 特殊阴影 | `0 0 20px rgba(255,182,193,0.5)` | 发光效果 |

### 4.2 阴影使用原则

1. **柔和自然**: 阴影扩散值要大，模糊要柔和
2. **色彩协调**: 可使用主题色的半透明阴影
3. **层次分明**: 根据层级使用不同深度的阴影
4. **避免过重**: 阴影透明度不超过20%

## 11. 动画规范

### 11.1 过渡时间

| 类型 | 时长 | 用途 |
|:---:|:---:|:---|
| 快速 | 150ms | 按钮反馈、颜色变化 |
| 正常 | 250ms | 弹窗出现、页面切换 |
| 慢速 | 400ms | 复杂动画、过渡效果 |

### 11.2 缓动函数

```
标准: cubic-bezier(0.4, 0, 0.2, 1)
进入: cubic-bezier(0, 0, 0.2, 1)
退出: cubic-bezier(0.4, 0, 1, 1)
弹性: cubic-bezier(0.68, -0.55, 0.265, 1.55)
```

## 13. 设计原则

### 13.1 一致性
- 所有界面遵循统一的色彩和字体规范
- 相同功能的组件保持一致的样式
- 动画效果保持统一的节奏

### 13.2 层次感
- 通过阴影和色彩区分层级
- 重要内容使用强调色突出
- 背景、内容、浮层层次分明

### 13.3 呼吸感
- 适当的留白让界面透气
- 避免过度拥挤的布局
- 使用柔和的色彩过渡

### 13.4 治愈感
- 圆润的形状和圆角
- 柔和的色彩搭配
- 自然的阴影和光效
- 可爱的图标和装饰
