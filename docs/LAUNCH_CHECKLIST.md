## 一、微信小程序注册与认证流程

### 1.1 注册前准备

| 序号 | 准备事项 | 说明 | 状态 |
|:---:|:---|:---|:---:|
| 1 | 未注册过微信公众平台的邮箱 | 163/QQ/Gmail 等均可 | ⬜ |
| 2 | 管理员身份证 | 需绑定本人银行卡的微信号 | ⬜ |
| 3 | 管理员手机号 | 接收验证码 | ⬜ |
| 4 | 企业营业执照(企业主体) | 个人主体不需要 | ⬜ |
| 5 | 对公账户(企业主体) | 微信认证/支付需验证 | ⬜ |
| 6 | 300元认证费(企业主体) | 微信认证年审费用 | ⬜ |

### 1.2 注册流程(个人主体)

```
步骤1: 访问 https://mp.weixin.qq.com/ → 点击"立即注册"
步骤2: 选择"小程序"账户类型
步骤3: 填写邮箱 → 登录邮箱 → 点击激活链接
步骤4: 选择主体类型: "个人"
步骤5: 填写管理员身份信息(姓名+身份证号)
步骤6: 管理员微信扫码验证
步骤7: 绑定管理员手机号 → 接收短信验证
步骤8: 填写小程序名称/头像/介绍(可后续修改)
步骤9: 审核(1-7个工作日)
步骤10: 审核通过 → 获取AppID
```

### 1.3 注册流程(企业主体)

```
步骤1-3: 同上
步骤4: 选择主体类型: "企业"
步骤5: 填写企业信息(名称/营业执照号)
步骤6: 填写管理员信息
步骤7: 对公账户打款验证(1-3个工作日)
步骤8: 微信认证(可选但推荐,需300元/年)
步骤9: 审核通过 → 获取AppID
步骤10: 开通微信支付(需认证后)
```

## 四、技术合规要求

### 4.1 代码包要求

| 要求项 | 限制值 | 检查方法 |
|:---|:---|:---|
| 主包大小 | ≤ 4MB | 微信开发者工具→详情→代码质量 |
| 分包大小 | ≤ 4MB/个 | 同上 |
| 总包大小 | ≤ 20MB(含分包) | 同上 |
| 启动页加载 | ≤ 5秒 | 真机测试 |
| 首屏可交互 | ≤ 3秒 | 真机测试 |

### 4.2 性能指标要求

| 指标 | 要求 | 说明 |
|:---|:---|:---|
| FPS | ≥ 30 fps | 战斗/动画场景 |
| 内存 | ≤ 500MB | 低端机需更低 |
| CPU | ≤ 60% | 持续运行不发热 |
| 流量 | 首次≤5MB | 尽量离线化 |
| 崩溃率 | ≤ 0.5% | 监控平台查看 |

### 4.3 隐私接口检查

```javascript
// 需在隐私政策中声明的接口
```

## 五、提交审核流程

### 5.1 提审前检查清单

```
□ 代码包大小符合要求(≤4MB主包)
□ 所有功能页面可正常访问
□ 没有死链/空白页面
□ 没有明显的UI错乱
□ 登录流程正常(获取微信授权→进入游戏)
□ 核心玩法完整(抽卡→战斗→合成→进化链路可走通)
□ 支付流程(如有)完整且安全
□ 广告(如有)可以正常观看
□ 隐私政策页面可访问
□ 用户协议页面可访问
□ 适龄提示已配置
□ 没有诱导分享/强制分享
□ 没有"分享到群可获奖励"类诱导
□ 游戏内有客服联系方式
□ 测试账号可正常使用(如提供)
```

### 5.2 提审步骤

```
步骤1: 微信开发者工具 → 上传代码
  - 版本号: 1.0.0
  - 项目备注: 首次提审，核心玩法版本

步骤2: 小程序后台 → 版本管理
  - 找到刚上传的"开发版本"
  - 点击"提交审核"

步骤3: 填写审核信息
  - 功能页面: pages/main/index (首页路径)
  - 功能截图: 上传3-5张游戏核心功能截图
  - 功能标签: 休闲游戏、养成、收集
  - 测试账号: [如需要] username / password
  - 备注: 说明游戏核心玩法和特色
  
步骤4: 提交 → 等待审核(1-7个工作日)

步骤5: 审核通过 → 点击"发布"
  - 发布后全网用户即可搜索和访问
```

### 5.3 审核常见拒绝原因与应对

| 拒绝原因 | 应对方案 | 优先级 |
|:---|:---|:---:|
| 服务类目不匹配 | 确认选择"游戏-休闲游戏" | 🔴 高 |
| 功能不完整/无法体验 | 确保核心玩法链路完整 | 🔴 高 |
| 缺乏必要资质(企业) | 办理《网络文化经营许可证》 | 🔴 高 |
| 隐私政策缺失/不规范 | 按要求完善隐私政策 | 🔴 高 |
| 诱导分享/关注 | 移除所有强制分享逻辑 | 🟡 中 |
| UI/UX体验差 | 优化交互流程，修复明显Bug | 🟡 中 |
| 虚拟支付未申请 | 先不开通支付功能，上线后再申请 | 🟡 中 |
| 含侵权内容 | 检查美术/音乐/文字版权 | 🟡 中 |
| 名称不合规 | 避免使用"官方""第一"等字眼 | 🟢 低 |
| 代码包过大 | 分包优化，图片压缩 | 🟢 低 |

### 5.4 审核加速技巧

```
1. 选择淡季提交(避开节假日前后)
2. 首次提交尽量精简功能(核心玩法版本)
3. 详细填写功能说明，附上玩法截图
4. 提供测试账号(免注册直接体验)
5. 在备注中友好说明游戏特色
6. 审核被拒后仔细阅读原因，一次性改完再提交(不要反复提交)
```
