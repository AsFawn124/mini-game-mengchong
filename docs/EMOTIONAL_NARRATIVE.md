# 🐾 萌宠大作战 — 情感叙事设计

---

## 核心情感主题

> **"每一次相遇，都是一次互相拯救。"**

萌宠不是战力数据。它们是朋友、家人、曾经孤独的灵魂。
你不是在"收集"它们——你是在"遇见"它们。

---

## 角色深度设计

### 玩家角色：被萌宠选择的人

开场时你在萌宠花园醒来。什么都不记得。

你不是天选之人。你只是一个被一只受伤的N级萌宠舔醒的普通人。

那只萌宠后来会成为你故事中最重要的伙伴——它不是最强的，但它从没离开过。

---

### 核心NPC

#### 艾琳 — 导师，27岁

表面：温柔可靠的前辈契约师，教你一切。

真相：她曾是混沌教会的核心成员。她的萌宠搭档在一次任务中为了保护她主动堕化了——这意味着它失去了所有记忆和理智，变成了只知道攻击的怪物。

她亲手封印了它。

她离开混沌教会的原因不是"觉悟了"，是她下不了第二次手。

**关键对话**（第三章，在她身份揭露后）：

```
"你以为我是好人？我只是一个逃跑的人。"

"你知道看着一起长大的伙伴用空洞的眼睛看着你，
然后你必须亲手把它——"
（停顿）

"抱歉。我又说多了。"

"我只是想说——
如果有一天你的萌宠也……
你要知道，那不是它们的错。
"
```

**隐藏场景**（羁绊系统：与艾琳对话10次后触发）：

深夜，艾琳在花园里对着一个空荡荡的契约球说话。

"今天来了个新人。和你刚来时一样笨。"

"我教他战斗。但我没告诉他战斗最可怕的不是输。"

"是赢了之后发现少了一只。"

"你不会想听这些。你以前就说我话多。"
"那我不说了。"

（沉默五秒）
"骗你的。我永远说不完。"

---

#### 阿尔文 — 混沌教会首领 / 艾琳的哥哥，32岁

表面：反派。想要释放混沌之力毁灭世界。

真相：他的萌宠——一只UR级暗系萌宠「虚无」——在裂界之灾中被混沌污染，介于生与死之间，永恒痛苦。他走遍世界寻找解药，发现唯一的办法是释放混沌——让世界法则重置。

他不是要毁灭世界。他是想救一只萌宠。以整个世界为代价。

**最终战前对话**：

```
"你知道虚无陪了我多少年吗？26年。"

"我6岁的时候在北境雪地里捡到它。它快冻死了，我也快冻死了。
我们抱在一起取暖，一起活了下来。"

"从那以后，它一次都没离开过我。
一次都没有。"

"现在我看着它每天在痛苦中抽搐，
而我什么也做不了——
我是最强的契约师，但我救不了它。"

"所以对不起了。
世界什么的，我不要了。
我只要它。"
```

**结局分支**：
- 选择理解：阿尔文在最后关头收手。虚无主动牺牲自己完成调和。阿尔文成为第六契约师。
- 选择对抗：击败阿尔文后，虚无为了救他耗尽最后的力量消失在混沌中。阿尔文抱着虚无留下的契约球，独自走进荒漠。从此没有人再见过他。

### 萌宠的故事

#### 拉拉 — 玩家第一只萌宠 (N级，草系)

它是那只舔醒你的萌宠。

它在游戏全过程中战力平平。不能进化。不能升星。永远是N。

但它会出现在每一个过场动画里：
- 战斗前在你脚边蹭来蹭去
- 你受伤时它会着急地转圈
- 你下线时它会趴在屏幕角落睡觉

**终章场景**：

混沌之心前，你即将进入最终战斗。
拉拉挡在你前面。

你没说话。它没动。

三秒后，你蹲下来摸了摸它的头。

游戏弹出对话框：
**「拉拉」的羁绊 MAX 达成。**
**获得：「永远的朋友」称号。**
**效果：全队不会战死。**

拉拉没有变强。它只是不让任何人死。

有些力量不是用来赢的。

#### 焰龙王的记忆（SSR，火系，Boss萌宠）

击败焰龙王后，你可以选择净化或契约。

如果选择净化——你会看到它的记忆：

```
「焰龙王的记忆碎片」

碎片1：
它还是一只小龙时，有一个小女孩每天来洞里给它带吃的。
小女孩叫它"阿火"。

碎片2：
小女孩长大了。来的次数越来越少。
最后一次来的时候，她穿着丧服。
"阿火，奶奶走了。"
"以后不能给你带吃的了。"
"我把家里的钥匙埋在洞口。你想我的时候就去看看。"

碎片3：
混沌入侵那天，小女孩已经老了。
她回到洞口，把阿火推进最深处。
"别出来。外面很危险。"
"我会回来的。我答应你。"
她没回来。

碎片4：
焰龙王一直在等。等了三十年。
混沌趁虚而入，利用它的等待——"她抛弃了你"——把它变成了堕化体。

碎片5：
你选择「净化」。
焰龙王变回了小龙。它看着你。
它的眼神像在问：她呢？
你没有答案。
```

如果选择契约——小龙会跟着你。它的技能描述里有一行小字：
"它还在等。但它愿意先帮你。"

#### 沧澜鲸的孤独（SSR，水系Boss）

它是大海里最后一只沧澜鲸。它已经独自游了三百年。

它不恨任何人。它只是太孤独了。

**战斗中**：
它全程不使用范围攻击。它只攻击靠近它的人——而且是轻轻地，像在提醒"别再靠近了"。

**净化后**：
你可以在深海遗迹的某处看到它。它不再攻击，只是浮在那里。

如果你坐在岸边（AFK30秒以上），它会靠近。你什么也不用做。它什么也不做。只是陪着你。

**羁绊Lv5时**：
它的技能里多了一个"陪伴"——没有任何战斗效果。使用后沧澜鲸会发出一声低鸣。屏幕外的回声很长很长。

---

#### 小石头 — 最早的契约师留下的萌宠（SR，草系）

在世界之树的核心，你发现了一个石头雕像——一只保持守护姿态的石龟。

碑文写着：
"我的契约师走不动了。她135岁，是上一个纪元最后的契约师。"

"她在生命最后一天解除了契约，说：'你还可以活很久。不要守着我。'"

"我没有离开。我变成了石头。"

"她以为解除契约我就自由了。"
"但她不知道——被爱过的东西，就再也回不去自由了。"

如果你选择不带走它的契约石：
它会继续守着。世界之树会在它身边多长出一棵小树苗。

如果你选择带走：
小石头会成为可召唤萌宠。它的技能是「守护誓言」——代替队友承受致命伤害。

## 情感系统设计

### 1. 萌宠日记系统

每只SR级以上的萌宠在被契约后，会解锁一本「日记」。日记的内容随羁绊等级解锁：

**羁绊Lv1**：它被契约的那一天
**羁绊Lv2**：它最喜欢/最害怕的事
**羁绊Lv3**：在被你契约之前，它经历过什么
**羁绊Lv4**：它想对你说但"说不出口"的话
**羁绊Lv5**：一封给你的信

**示例 — 火凤雏（SSR）的日记**：

```
Lv1：今天一个奇怪的人类和我打了一架。我输了。但他说"跟我走吧"。我居然同意了。

Lv2：我喜欢晒早上的太阳。不喜欢下雨——洗羽毛太麻烦了。
     他（你）好像知道。每次下雨都把我收进契约球。

Lv3：我以前的主人是个铁匠。他不喜欢我——他觉得火系萌宠只会给他添乱。
     后来他把我卖给了一个商人。商人把我关在笼子里展览。
     我逃出来了。但我不确定这次会不会又被卖掉。

Lv4：（这页被泪水打湿过）
     今天你在商店里有人出高价买我。
     你拒绝了。
     你甚至没犹豫。
     我假装在睡觉。但我看见了。

Lv5：以前我不知道"家"是什么意思。
     现在知道了。
     就是你。
     不要卖掉我。
```

### 2. NPC好感度隐藏事件

| NPC | 好感度触发条件 | 隐藏事件 |
|-----|------|------|
| 艾琳 | 每天和她对话 | 她最终会带你去封印她旧搭档的地方，问你她做对了吗 |
| 阿尔文 | 战斗中不放终极技 | 他在被打败时苦笑："你这种烂好人……和艾琳一样。" |
| 老王(道具商) | 买够100次 | 给你一个旧怀表："这是我女儿的东西。她没有成为契约师的天赋。替她看看吧。" |
| 公会会长 | 在公会战中贡献最高 | 私下告诉你他在现实中的职业是幼儿园老师 |

### 3. 节日特殊剧情

| 节日 | 剧情 |
|------|------|
| 春节 | 萌宠们偷偷给你准备了礼物——每只萌宠送一个小东西（树枝、发光石头、褪色的花瓣） |
| 中秋 | 艾琳和阿尔文（如果和解了）坐在一起看月亮。全程没有对话。只有画面 |

| 你的生日 | 你第一次登录游戏时填的日期。那天所有NPC在城里给你庆祝 |

## 情感触发场景

### 场景：拉拉的最后一天

```
（触发条件：羁绊MAX + 完成终章）

【一个普通的午后，萌宠花园】

拉拉没有像平时一样围着你转。
它坐在花园的角落，看着太阳。

你走过去坐下。
它靠在你腿上。

画面变成插画风格——
不是高清，是水彩。像一本儿童绘本。

画面1：拉拉舔醒昏迷的你
画面2：拉拉第一次战斗，吓到躲在你的腿后面
画面3：拉拉在篝火旁睡着了，你把外套披在它身上
画面4：拉拉试图挡在你和混沌化身之间——虽然它只有10级
画面5：现在——它靠在你腿上，闭着眼睛

旁白：
"它没有变强过。但这从来不是重点。"
"它只是你旅途的开始。"
"所以你走到哪里，它就在哪里。"

"一只N级萌宠的故事。"
"也是你的故事。"
```

## 叙事原则

1. **萌宠不是宠物，是角色** — 每只都有过去、恐惧和愿望
2. **温暖比悲情更有力量** — 末世当然苦，但日常的甜更动人
3. **用沉默说最多的话** — 最重的情绪不需要台词
4. **选择有代价** — 净化/契约、理解/对抗，双线都有缺憾
5. **给玩家留白** — 不要解释一切。最好的故事是玩家自己补完的
