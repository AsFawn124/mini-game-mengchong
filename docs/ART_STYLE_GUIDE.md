### 2.2 辅助色

| 色彩名称 | 色值 | 用途 |
|:---:|:---:|:---|
| **薰衣草紫** | `#E6E6FA` | SR级萌宠主题色 |

| **星空蓝** | `#B0C4DE` | SSR级萌宠主题色 |

### 2.3 稀有度色彩体系

| 稀有度 | 主题色 | 边框色 | 光效色 |
|:---:|:---:|:---:|:---:|
| N (普通) | `#90EE90` | `#98FB98` | `#E0FFE0` |
| R (稀有) | `#FFDAB9` | `#FFA500` | `#FFE4B5` |
| SR (超稀有) | `#E6E6FA` | `#9370DB` | `#DDA0DD` |
| SSR (传说) | `#B0C4DE` | `#4169E1` | `#87CEFA` |

### 2.4 色彩使用原则

1. **60-30-10法则**
   - 60% 主色调/背景色
   - 30% 辅助色/次要元素
   - 10% 强调色/重点元素

2. **水彩晕染效果**
   - 色彩边缘使用柔和渐变
   - 避免锐利色块边界
   - 适当留白营造透气感

## 3. 萌宠设计规范

### 3.1 造型原则

#### 基础比例
- **头身比**: 1:1 或 1:1.2 (大头小身，Q版可爱)
- **眼睛**: 占脸部 1/3，大而圆，高光明显
- **身体**: 圆润饱满，避免尖锐棱角
- **四肢**: 短粗可爱，动作夸张

#### 风格特征
```
✅ 推荐:
- 圆润的线条和形状
- 大眼睛、小嘴巴
- 柔和的光影过渡
- 水彩质感的毛发/皮肤
- 可爱的表情和姿态

❌ 避免:
- 尖锐的棱角
- 写实的比例
- 过于复杂的细节
- 暗沉的色调
- 恐怖或攻击性元素
```

### 3.2 各稀有度设计差异

#### N级 (普通) - 基础可爱
- 简单的动物原型
- 基础色彩搭配
- 标准Q版比例
- 例如: 小兔子、小猫、小狗

#### R级 (稀有) - 特色鲜明
- 独特的造型特征
- 渐变色运用
- 小型装饰元素
- 例如: 戴蝴蝶结的兔子、穿马甲的小猫

#### SR级 (超稀有) - 华丽精致
- 复杂的服装设计
- 特效元素(光晕、粒子)
- 独特的配色方案
- 例如: 魔法少女兔、骑士小猫

#### SSR级 (传说) - 梦幻传说
- 神话/幻想元素
- 华丽的特效和光晕
- 独特的造型和姿态
- 例如: 天使兔、龙猫骑士、凤凰幼崽

### 3.3 萌宠分类设计

| 分类 | 设计特征 | 代表元素 |
|:---:|:---|:---|
| **毛茸茸系** | 蓬松毛发、圆润体型 | 兔子、猫咪、小狗、羊驼 |
| **鳞片系** | 光滑皮肤、可爱龙角 | 小龙、蜥蜴、恐龙 |
| **羽翼系** | 柔软翅膀、轻盈姿态 | 小鸟、猫头鹰、天使 |
| **魔法系** | 神秘光效、奇幻元素 | 精灵、独角兽、魔法生物 |
| **自然系** | 植物元素、自然色彩 | 花精灵、树精、蘑菇怪 |

## 4. UI设计规范

### 4.1 界面布局

#### 安全区域
- 顶部预留: 60px (状态栏)
- 底部预留: 80px (操作区)
- 边距: 20px

#### 布局原则
- 居中对称为主
- 重要信息放在视觉中心
- 操作按钮放在拇指可及区域

### 4.2 组件规范

#### 按钮
```
普通按钮:
- 高度: 80px
- 圆角: 40px (全圆角)
- 背景: 渐变色
- 阴影: 柔和投影
- 文字: 粗体，白色

重要按钮:
- 添加光晕效果
- 微动画反馈
- 尺寸比普通大20%
```

#### 卡片
```
萌宠卡片:
- 圆角: 20px
- 背景: 半透明白色
- 边框: 根据稀有度变色
- 阴影: 柔和投影
- 内边距: 16px
```

#### 面板
```
弹窗面板:
- 圆角: 30px
- 背景: 米白色 (#FFFAF0)
- 边框: 2px 柔和色
- 标题栏: 渐变色背景
```

### 4.3 字体规范

| 用途 | 字体 | 大小 | 颜色 |
|:---:|:---|:---:|:---:|
| 标题 | 圆润黑体 | 48px | `#333333` |
| 副标题 | 圆润黑体 | 32px | `#666666` |
| 正文 | 圆润黑体 | 24px | `#666666` |
| 按钮文字 | 粗体 | 28px | `#FFFFFF` |
| 数字 | 等宽字体 | 36px | 根据用途 |

### 4.4 图标规范

- 风格: 线性图标 + 填充图标结合
- 圆角: 所有拐角 2px 圆角
- 描边: 2px 粗细
- 尺寸: 24px / 32px / 48px 三种规格

## 6. 输出规范

### 6.1 图片规格

| 用途 | 尺寸 | 格式 | 背景 |
|:---:|:---:|:---:|:---:|
| 萌宠原画 | 512x512 | PNG | 透明 |
| 萌宠头像 | 128x128 | PNG | 透明 |
| UI按钮 | 可变 | PNG | 透明 |
| 背景图 | 750x1334 | JPG/PNG | 填充 |
| 图标 | 64x64 | PNG | 透明 |

### 6.2 命名规范

```
萌宠图片: pet_{编号}_{稀有度}.png
  例如: pet_001_n.png, pet_025_sr.png

UI素材: ui_{界面}_{元素}_{状态}.png
  例如: ui_main_button_start.png, ui_battle_icon_pause.png

特效: fx_{效果名}_{编号}.png
  例如: fx_star_01.png, fx_glow_02.png
```

### 6.3 文件大小

- 萌宠原画: < 200KB
- UI素材: < 100KB
- 特效: < 50KB
- 背景图: < 500KB
